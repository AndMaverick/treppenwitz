---

## 🚀 Funktionen  
- **Aufgaben zählen** — sofortige Übersicht  
- **Wichtige Begriffe extrahieren** — Schlüsselwörter auf einen Blick  
- **Priorität erkennen** — hohe vs. niedrige Dringlichkeit  
- **Handlungsempfehlungen** — nächste Schritte vorschlagen
